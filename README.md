# Next.js Project

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app), configured with **TypeScript**, **Tailwind CSS**, and **Parkinsans** font from [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts).

---

## 🚀 Getting Started

First, install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see your application.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

---

## 🎨 Styling with Tailwind CSS

This project uses [Tailwind CSS](https://tailwindcss.com/) for styling. Tailwind is already configured and ready to use in `globals.css`.

Example usage in a component:

```tsx
export default function Example() {
  return <h1 className="text-3xl font-bold text-blue-600">Hello Tailwind!</h1>;
}
```

---

## 🔠 Fonts with `next/font`

This project uses the [Parkinsans](https://fonts.google.com/specimen/Parkinsans) font via the Next.js font optimization API.

Configured in `app/layout.tsx`:

```tsx
import "./globals.css";
import { Parkinsans } from "next/font/google";

const parkinsans = Parkinsans({ subsets: ["latin"], variable: "--font-parkinsans" });

export const metadata = {
  title: "Next.js App",
  description: "Generated by create-next-app with Parkinsans font",
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={parkinsans.variable}>
      <body>{children}</body>
    </html>
  );
}
```
